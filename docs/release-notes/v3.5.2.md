
# MaojuPlayer v3.5.2

This is the first public release of MaojuPlayer, a free, audiophile-grade music player for macOS, Windows and Linux.

## Before you install

* **Windows: install the Visual C++ Redistributable first.** MaojuPlayer needs Microsoft's C runtime. Without it, Windows shows "The code execution cannot proceed because VCRUNTIME140.dll was not found" and MaojuPlayer does not start.
  * Download and run Microsoft's installer: **[vc_redist.x64.exe](https://aka.ms/vc14/vc_redist.x64.exe)**, then click **Install**.
  * Or, in a terminal: `winget install Microsoft.VCRedist.2015+.x64`
  * Installing it again is harmless. An older installed version can be too old, so install the latest one.
* **Windows SmartScreen:** if Windows shows "Windows protected your PC", click **More info → Run anyway**.
* **macOS Gatekeeper:** if macOS says it cannot verify the app, open **System Settings → Privacy & Security**, click **Open Anyway** next to the MaojuPlayer message, then confirm.

## Verify your download

Every release includes a `SHA256SUMS` file. Put it in the same folder as your download, then run:

```sh
shasum -a 256 -c SHA256SUMS --ignore-missing      # macOS
sha256sum -c SHA256SUMS --ignore-missing          # Linux
```

On Windows (PowerShell): `Get-FileHash .\<file> -Algorithm SHA256`, then compare the result with the matching line in `SHA256SUMS`.

## Highlights

* **Bit-perfect playback** with exclusive access to your DAC, and native DSD (DSF/DFF).
* **DSP chain:** 10-band parametric EQ that adds headroom automatically so its boosts do not clip, headphone crossfeed, and room correction (convolution).
* **Gapless playback and crossfade.**
* **Streaming:** Qobuz and Tidal (your own subscription), Internet radio, and Roon control.
* **Lyrics** with timing you can edit and sync yourself.
* **Tile-based layout** you can edit, many visualizers, and more than 90 interface languages.
* **Update check:** MaojuPlayer tells you when a new version is published (Help → About).

Full list of changes: [CHANGELOG.md](https://github.com/sfchun/MaojuPlayer-Releases/blob/main/CHANGELOG.md).

## Known limitations

* **Right-to-left languages are experimental:** Arabic, Hebrew, Persian and Urdu. Text is not laid out right to left yet: it may be left-aligned, and mixed right-to-left and Latin text may appear in the wrong order.
* **Linux ARM64 is experimental:** it is cross-compiled and not tested, and it cannot play WavPack files.
* **Tidal:** the Featured tab is not available.
* The apps are not signed yet, so macOS and Windows warn you on first launch (see "Before you install").

## Privacy

MaojuPlayer has no telemetry and no analytics. It checks for a new version **at most once a day, at startup**, with one request to GitHub (`api.github.com`) that sends only your IP address and the app's user agent (`MaojuPlayer/<version> ( https://github.com/sfchun/MaojuPlayer-Releases )`). Nothing is downloaded or installed: it only tells you that a new version exists. To turn it off, open **Help → About** and untick **Check for updates automatically**. You can still click **Check now** at any time.

# Security policy

## Reporting a vulnerability

If you find a security problem in MaojuPlayer, for example a crash or code execution triggered by a crafted audio, playlist, CUE or lyrics file, a malicious stream or server response, or credentials exposed in logs or files, please report it privately:

* **[Report a vulnerability](https://github.com/sfchun/MaojuPlayer-Releases/security/advisories/new)** (GitHub private vulnerability reporting). Only the maintainer can see your report.

Please include the MaojuPlayer version (Help → About), your operating system, and the steps or a sample file that reproduce the problem. Please do not open a public issue or publish details before a fixed version is released.

Security reports are accepted from everyone; a GitHub Sponsors subscription is not required.

## Supported versions

Only the latest release receives security fixes. Please update before reporting.
